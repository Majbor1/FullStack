    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa

    Note right of browser: The browser sends an AJAX request with the JSON payload: { "content": "New SPA note", "date": "2026-09-16" }
    Note left of server: The server parses the JSON and adds the note to the array in memory
    server-->>browser: HTTP 201 Created ({"message":"note created"})
    deactivate server
